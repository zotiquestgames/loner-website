Loner Creator's Kit

If you wish to develop your own Geared Towards Loner game, you are welcome to do so. The Creative Commons license has been put in place for this purpose.

Open Creator's Kit Files

License

Loner is a product of Zotiquest Games. Its full text is available for use under the Creative Commons Attribution Share-Alike CC BY-SA 4.0 license.

To make your own Geared Towards Loner game, simply include the following text in your game:

Required Attribution Text
This work is an independent production by [Publisher Name] and is based on Loner, developed and authored by Roberto Bisceglie, and licensed for our use under the Creative Commons Attribution 4.0 License. [Publisher Name] is not affiliated with Zotiquest Games.

Stamp

If you want, you may use the official "Geared Towards Loner" stamp to identify your game as part of the line. You'll find the PNG file in the Creator's Kit folder above.

System Reference Document

The text of the Loner System Reference Document, containing all the Core Rules, is available at lonersrd.zotiquestgames.com.

Template

To help creators develop their game, Zotiquest Games provides a template in two flavors:

Affinity Publisher Package
Maintains the original Loner trade dress, including typefaces. Use per the License, or modify it, just make clear your game is an independent production not affiliated with Zotiquest Games.
Raw Text File
For creators who want to develop the text first and think about layout later.
